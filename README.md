# 3D-Printable-Designs

A curated collection of 3D models I've designed for printing on FDM/FFF 3D printers.

## 🎯 Projects

[AC Window Hose Adapter](./AC%20Window%20Hose%20Adapter/)
Parametric adjustable window AC air vent system with threaded airflow control.

[Office Chair Brake](./Office%20Chair%20Brake/)
Locking brake mechanism designed to prevent office chairs from rolling away.

[Schuko Wall Mount](./Schuko%20Wall%20Mount/)
Parametric 3D printable wall mount for European Schuko electrical sockets.

[Wireless Charging Station](./WirelessChargingStation/)
Parametric DIY wireless charger combining 3D printing and laser engraving.
